Guarda aquí tus programas HTML (por ejemplo: dimensionador.html, descargador-videos.html, etc.).

Al subirlos a GitHub (shewinho/palmaestro-web) con GitHub Pages activo, quedarán publicados automáticamente en:
https://shewinho.github.io/palmaestro-web/apps/nombre-de-tu-app.html

Además, dentro de cualquier app HTML puedes heredar toda la estética y el loader con solo estas 2 líneas:
<link rel="stylesheet" href="../theme/palmaestro-theme.css" />
<script src="../loader/palmaestro-loader.js"></script>
